# Primeiros passos com IA

Se você nunca usou uma IA como o ChatGPT para algo além de uma pergunta rápida, comece por aqui. São três leituras curtas:

1. **[Qual IA usar]({% link primeiros-passos/qual-ia-usar.md %})**: as opções gratuitas e como criar sua conta.
2. **[Como usar um prompt]({% link primeiros-passos/como-usar-um-prompt.md %})**: copiar, colar, anexar o currículo e completar os campos.
3. **[Cuidados ao usar IA]({% link primeiros-passos/cuidados.md %})**: o que não compartilhar e por que conferir tudo o que a IA responde.

## O que é um "prompt"?

**Prompt** é só o nome dado à mensagem que você envia para a IA. Um prompt bem escrito explica para a IA **quem ela deve ser** (por exemplo, "um recrutador experiente"), **o que ela deve fazer** e **como deve responder**.

Os prompts deste site já vêm prontos e testados. Você só copia, cola e completa as informações que são suas.
