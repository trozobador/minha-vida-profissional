# Qual IA usar

Os prompts deste site funcionam nas principais IAs. Todas têm uma versão **gratuita**, que funciona no navegador do computador ou num aplicativo de celular:

| IA | Site | Empresa |
|:---|:-----|:--------|
| ChatGPT | [chatgpt.com](https://chatgpt.com) | OpenAI |
| Claude | [claude.ai](https://claude.ai) | Anthropic |
| Gemini | [gemini.google.com](https://gemini.google.com) | Google |

## Qual escolher?

Qualquer uma serve para começar. Se você já tem conta em alguma delas, use essa. Se não tem nenhuma, escolha a que achar mais fácil de usar. Criar a conta leva poucos minutos e normalmente dá para entrar com a conta do Google.

{: .dica }
Se uma resposta não ficou boa, vale testar o mesmo prompt em outra IA. Elas têm "estilos" diferentes e uma pode se sair melhor que a outra em certas tarefas.

## Limites da versão gratuita

As versões gratuitas costumam ter um **limite de mensagens** por dia ou por algumas horas, e às vezes um limite de arquivos anexados. Se você chegar no limite, espere um pouco ou continue em outra IA.

Para os prompts deste site, a versão gratuita é suficiente na maioria dos casos.
